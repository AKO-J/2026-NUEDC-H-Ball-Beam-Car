# SMARTCAR 核心总览

更新时间：2026-09-05

## 结题状态

项目已参加省级电子设计竞赛并获得三等奖，现已停止主动开发并进入只读归档。赛场上支撑球杆机构的支架底部热熔胶松动，第三题小球控制未能稳定完成；5 度微调不够细且逐项调试耗时过多。完整证据边界与复盘见根目录 `PROJECT_CLOSURE.md`。

## 项目目标

使用 K230 视觉检测摆杆内钢球位置，由 MSPM0G3507 控制 X42S 步进机构连续微调摆杆；同时完成 LF04 循迹、车轮驱动、按键选择、OLED 提示、急停和实验留档。最终结果必须安全、可复现，并能区分软件验证、烧录验证和实物验收。
