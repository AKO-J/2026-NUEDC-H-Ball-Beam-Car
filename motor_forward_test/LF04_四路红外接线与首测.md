# LF04 四路红外接线与首测

## 最终接口分配

LF04 插座按板上丝印为 `O1 O2 O3 O4 VCC GND`，四路都是独立数字输出，不是 I2C。

| LF04 | LP-MSPM0G3507 | 40 针位置 | 方向 |
| --- | --- | ---: | --- |
| `O1` | `PB18` | 25 | LF04 → MCU |
| `O2` | `PA24` | 27 | LF04 → MCU |
| `O3` | `PA17` | 28 | LF04 → MCU |
| `O4` | `PA12` | 32 | LF04 → MCU |
| `VCC` | 首测接 `3V3` | — | 主控 → LF04 |
| `GND` | `GND` | — | 必须共地 |

`PA10`（34）和 `PA11`（33）保留给板载 XDS110 的 UART/ROM-BSL，`PA18`（26）
保留给 BSL 引导；LF04 不得连接这三根线。四根 LF04 信号线可以直接按表中的
25、27、28、32 号排针接，不需要改 J8、J21 或 J22。

厂家原理图确认：探头面朝下时，物理左到右为 `O4 → O3 → O2 → O1`。正式任务 2 已按
`O1` 在右侧（`H_TRACK_IR_O1_IS_LEFT = 0U`）编译；如实际安装翻转，只改这一项，不要交叉改四根线。
厂家真值表使用“白底为 `1`、黑线为 `0`”，正式代码已按黑线低有效编译。

## 电平安全

1. 第一次先不给电机上电，只给主控和 LF04 供电。
2. 优先尝试 `VCC=3.3V`，分别把每个探头放在白底和黑线上，用万用表测 `O1~O4` 对 GND 的电压。
3. 若 3.3V 下四路能可靠翻转，保持 3.3V 供电并直接接 MCU。
4. 若该批次必须使用 5V，必须先测输出；任何一路高电平超过 3.6V，都要经过四路电平转换或分压后再接 MSPM0。
5. 正式代码按“黑线输出低电平”配置。若首测与此相反，停止电机测试并先复核模块接线、供电和电位器标定。

## 只读首测

构建不会驱动电机的 LF04 测试固件：

```sh
cd motor_forward_test
make ir-line-sensor-read-test
```

确认车轮悬空、LF04 输出电平安全后再烧录：

```sh
make flash-ir-line-sensor-read-test
```

CCS Watch 中观察：

- `g_ir_raw_mask`：位 0~3 分别对应 `O1~O4` 的原始电平；
- `g_ir_o1`~`g_ir_o4`：每路独立原始电平；
- `g_ir_black_if_high_mask`：假设黑线为高时的黑线掩码；
- `g_ir_black_if_low_mask`：假设黑线为低时的黑线掩码；
- `g_ir_black_left_to_right_mask`：按正式安装方向归一后的黑线掩码，bit0 为车左；
- `g_ir_dh_white_state`：厂家 `DH1 DH2 DH3 DH4` 状态（白=`1`、黑=`0`）；
- `g_ir_sample_count`：持续增加表示程序正在采样。

OLED 已接时，首测固件会直接显示 `RAW: O1 O2 O3 O4` 和
`BLACK: O1 O2 O3 O4`，不必打开 CCS Watch。`RAW` 应在白底为 `1111`、
黑线为 `0000`；`BLACK` 正好相反。若 OLED 未显示，板载 LED1 每 500 ms
翻转仍表示读取程序正在运行。

每个探头必须分别完成白底、黑线测试；模块离赛道约 `30 mm`，把电位器调至黑线上识别灯刚亮、白底熄灭。
随后记录：正常连续黑线的 `DH1 DH2 DH3 DH4` 状态（期望居中 `1001`），以及 A 点横线的 `0000`。

## 与 ICM、OLED 的并行接线

| 模块 | 信号 | MSPM0 引脚 |
| --- | --- | --- |
| ICM42688 | `SCL` / `SDA` | `PA31` / `PA28`（硬件 I2C0） |
| SSD1306 OLED | `SCL` / `SDA` | `PB19`（J3.23）/ `PA15`（J3.30）（软件 I2C） |
| LF04 | `O1~O4` | `PB18 / PA24 / PA17 / PA12`（GPIO） |

三组接口互不冲突。OLED 的 `VCC` 接 `3V3`、`GND` 接公共地；禁止使用 `PA18` 作为 OLED SDA，也禁止用 `PB13`（X42S 的 `Stp`）。
