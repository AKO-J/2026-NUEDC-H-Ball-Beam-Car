# 摆杆小球：提速、加速度与预测制动综合指导

## 1. 先区分三种“速度”

| 名称 | 当前来源 | 能解决什么 | 不能直接解决什么 |
|---|---|---|---|
| 电机脉冲速度 | `stepper_beam.c` | 白杆到达命令姿态的滞后 | 小球自身惯性、视觉延迟 |
| 小球加速度 | 白杆相对倾角 / POS | 小球从 0 到 ±5 cm 的运行时间 | 电机跟随不够快 |
| 视觉更新率 | K230 检测帧率 | 位置和速度估计的延迟 | 白杆实际可提供的加速度 |

不要只提高一种速度。电机加速而视觉、制动不变，会让小球更容易冲过 −5 cm；增大白杆倾角而电机不够快，则倾角命令到位太迟。

## 2. 当前有效控制基准

### 2.1 白杆标定边界

白杆角度与电机轴角度不能混用。控制层只允许使用标定的相对 POS 范围：

```text
−132 ≤ P_control ≤ +132
```

每次角度到 POS 必须按 `X42S_白杆首次标定结果_2026-07-31.md` 第 5 节相邻点线性插值。最终电机位置为：

\[
P_{motor}=P_{level}+P_{control}
\]

`P_level` 是第二次 START 保存的水平参考；不是白杆角度。

### 2.2 当前任务 3 参数快照

| 项目 | 当前值 | 含义 |
|---|---:|---|
| +5 目标 | `+61 px` | 约 +5 cm |
| −5 目标 | `−59 px` | 约 −5 cm |
| `Kp` | `11 mdeg/px` | 位置误差转倾角 |
| +5 近端最大 | 相对 `POS +80` | 约 +989 mdeg |
| −5 远端驱动 | 相对 `POS −50` | 约 −565 mdeg |
| −5 近端驱动 | 相对 `POS −10` | 约 −101 mdeg |
| −5 预测反向制动 | 相对 `POS +10` | 约 +101 mdeg |
| 预测制动减速度 | `100 px/s²` | 经验模型参数，非视觉二阶差分 |
| 制动安全余量 | `14 px` | 预测越界前提前制动 |

## 3. 电机如何提速

当前脉冲参数在 `stepper_beam.c`：

```text
起步速度：100 PPS
最高速度：400 PPS
加速度：200 PPS²
```

这组数偏保守。尤其“最低点 POS 0 → POS −596”的预置动作，按此参数会有明显爬升时间。

### 推荐测试阶梯

一次只改一组，先空载或不放球测试 10 次，确认无丢步、异响、撞端点后再进入下一组。

| 阶段 | 起步 PPS | 最大 PPS | 加速度 PPS² | 通过条件 |
|---|---:|---:|---:|---|
| 当前基准 | 100 | 400 | 200 | 已知可运行 |
| A | 100 | 600 | 500 | 10 次位置一致、无卡顿 |
| B | 120 | 800 | 800 | 无丢步、无明显共振 |
| C | 150 | 1000 | 1200 | 仅在 B 稳定后尝试 |

若出现“电机声音变尖但白杆未到位”，这是丢步或扭矩不足，应退回上一档。提高最大 PPS 不能弥补机械联动松动、齿隙或电源电流不足。

## 4. 如何让小球跑得更快

### 到 +5 cm

小球初段加速度主要来自正向白杆倾角。当前近端上限为相对 `POS +80`；若仍慢，可优先检查：

1. 电机是否在目标变化后实际快速到位；
2. 白杆联动是否有松动或打滑；
3. +5 近端限幅是否过早进入。

不要直接把 POS 改到未标定范围外。任何新 POS 都必须先由标定表相邻点插值为 mdeg，再送入控制器。

### 到 −5 cm

远端 `POS −50` 决定初段左移加速度；更负会更快，也会增加刹车难度。调速顺序应是：

```text
先提高电机 PPS/加速度
→ 再微调远端 POS
→ 最后重标定预测制动
```

## 5. α-β 预测落点制动

视觉每次新帧先估计平滑位置与速度，不直接计算抖动很大的视觉加速度。

\[
x_{pred}=\hat{x}+\hat{v}T
\]

当前前视时间 `T=50 ms`。当球左移时，使用经验反向制动能力估计停车距离：

\[
d_{stop}=\frac{v^2}{2a_{brake}}
\]

\[
x_{stop}=x_{pred}-d_{stop}
\]

若 `x_stop` 到达或越过 `−5 cm + 安全余量`，切换到反向制动 `POS +10`。

### −5 cm 现象 → 调哪个数据

| 现象 | 首先改什么 | 改动方向 |
|---|---|---|
| 明显冲过 −5 | `a_brake` | 降低，例如 100 → 80，预测更早制动 |
| 仍略冲过 | 安全余量 | 提高，例如 14 → 18 px |
| 已提前制动但依旧刹不住 | 反向制动 POS | `+10 → +20`，须标定表插值 |
| 还没到 −5 就停 | `a_brake` 或余量 | 增大减速度，或降低余量 |
| 到 −5 附近仍缓慢左漂 | 近端 POS | `−10 → 0` 或更接近零 |

每次只改一项，并记录“切换制动时 x、速度 v、最终停止 x”。有这些记录后，才能把 `a_brake` 从经验值改为实测值。

## 6. 视觉侧提速与稳定性

当前 K230 实测检测约 22 FPS，视觉帧间隔约 45 ms。串口提高发送频率不能制造新的视觉坐标；应优先：

1. 保持真实水管 ROI 裁剪；
2. 关闭 IDE 图像显示用于正式跑控；
3. 只保留最高置信度的小球框；
4. 降低无关绘制和终端打印；
5. 保持 UART 只发送二进制/短帧坐标，不打印调试日志；
6. 使用 α-β 前视补偿帧间延迟。

若模型推理本身仍是约 22 FPS，优先保证检测稳定性；盲目提高相机采集 FPS 不会等比例提高有效检测 FPS。

## 7. 每次调参的安全流程

1. 先断电或复位，把机构轻靠最低机械点；
2. 第一次 START：`POS 0 → POS −596` 预置抬升；
3. 第二次 START：保存 `P_level`；
4. 第三次 START：启动任务；
5. 先不放球检查白杆方向，再放球测试；
6. 每项参数连续测试至少 5 次，记录成功次数、+5 位置、−5 位置、总时间；
7. 出现撞端点、异响、丢步时立即停止并退回上一档。

## 8. 推荐下一步

先保持现有小球控制参数不变，只进行电机“阶段 A”空载测试：`400 PPS/200 PPS² → 600 PPS/500 PPS²`。通过后，再在同一速度下重新测一次 −5 cm 制动，避免把电机响应变化误判成预测模型错误。
