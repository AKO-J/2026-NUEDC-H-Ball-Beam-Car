# H 题 1–40 排针总表

本表以 LP-MSPM0G3507 用户提供的 1–40 图为唯一定位依据。它是当前 H 题布线的
总表；电机和编码器保留已验证的电气功能，LF04 从 PA10/PA11 迁出，所有新信号均
使用标准 40 针排针。

## 必须改接的线

断开电源后执行：

| 原线 | 新线 |
| --- | --- |
| LF04 `O1: PA10(34)` | `PB18(25)` |
| LF04 `O2: PA11(33)` | `PA24(27)` |
| LF04 `O3: PA12(32)` | `PA17(28)` |
| LF04 `O4: PA17(27)` | `PA12(32)` |
| TB6612 `AIN2: PB26`（非 40 针排针） | `PB17(18)` |

新的 LF04 线序仍以模块插座丝印 `O1/O2/O3/O4` 为准，不能按线的左右位置猜测。
代码已同步更新；接线未完成前不要接 LF04 上电。

## 永久保留，不接车载模块

| 40 针号 | 引脚 | 原因 |
| ---: | --- | --- |
| 26 | `PA18` | `S1` BSL 引导输入。 |
| 33 / 34 | `PA11 / PA10` | 默认连接板载 XDS110 UART，并用于 ROM-BSL 排障。 |
| — | `PA19 / PA20` | SWDIO / SWCLK，虽不在 40 针排针上，但任何外设都不得接。 |
| 16 | `NRST` | 仅复位。 |
| 21 | `5V` | 不给任何 MSPM0 信号或 3.3 V 外设供电。 |
| 24 | `PA22` | 板载光敏/运放线路相关，当前不使用。 |

## 现场接线顺序

1. 只接 USB，先完成 LF04 的 `VCC/GND/O1–O4` 改线。
2. 烧录 `ir-line-sensor-read-test`，逐路验证四个原始位；此测试不驱动电机。
3. 接回 OLED，运行 OLED 测试；再接 ICM 做 I2C 测试。
4. 最后接 TB6612 信号线和电机电源。首次验证时车轮必须悬空；AIN2 改线后，先做单轮低速方向检查。

任何 5 V 供电的 LF04 都不得将其 `O1–O4` 直接接入上述 GPIO；先确认输出最高不超过
3.3 V，或添加四路电平转换。
