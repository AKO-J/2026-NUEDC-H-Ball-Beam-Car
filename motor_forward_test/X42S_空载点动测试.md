# X42S 白杆（摆杆）手动零点与 5° 标定

该固件不使用机械限位开关，也不会自动寻找机械原点。当前使用的 `stepper-fine-jog-test`
只做安全的相对点动：每次 `UP/DOWN` 为 `±44` 脉冲，约为电机轴 `±4.95°`。
白杆实际转角不能按电机轴角直接换算，必须按下表实测。

## 1. 接线与通电前检查

首次实验不要放钢球，12 V 直流电源先限流 `1 A`。

| X42S 端子 | 连接 |
|---|---|
| `V+` | 12 V 正极 |
| `Gnd` | 12 V 负极 |
| `Com` | LP-MSPM0G3507 的 `3V3` |
| `Stp` | `PB13`（35号脚） |
| `Dir` | `PB12`（19号脚） |
| `En` | `PB6`（13号脚） |

按键均为常开按键，按下时把 GPIO 接到开发板 `GND`：

| 按键 | GPIO / 40针脚位 |
|---|---|
| `START` | `PB7` / 14号脚 |
| `UP` | `PB15` / 17号脚 |
| `DOWN` | `PB8` / 15号脚 |

不需要 `OK`、`MODE` 或限位开关，`PB0` 保持悬空。`Com` 不是地线，不要把
12 V 接到开发板 GPIO。

OLED 固定为：`VCC→3V3`、`GND→GND`、`SCL→PB19`（23号脚）、
`SDA→PA15`（30号脚）。

在 X42S 屏幕确认：`P_Pul=PUL_ENA`、`En=Hold`、`MStep=16`。不要执行
`Cal_MFL`，它会让电机高速转动多圈。

## 2. 构建与烧录

```sh
cd motor_forward_test
make stepper-fine-jog-test
./flash_xds110.sh --yes --run build/stepper_fine_jog_test.out
```

烧录并重新上电后，OLED 应显示：

```text
X42S FINE JOG TEST
44P = 4.95D MOTOR
DISARMED
STOPPED
POS +0
UP/DN: +/-44 PULSE
```

## 3. 每次测试前确认手动零点

1. 用水平尺观察白杆（或水管），短按 `START` 解锁。
2. 单次点按 `UP/DOWN`，每次为 `44` 脉冲；必须等 OLED 从 `MOVING` 变为
   `STOPPED` 后才可进行下一次点按。
3. 调到白杆水平后，按一次 `START` 锁定，然后按开发板 `RESET`（或断电重上电）。
   重启后 OLED 的 `POS +0` 就是这次测试的软件零点；**不要再移动白杆**。
4. 再按一次 `START` 解锁，开始下表测试。

按 `START` 可锁定/解锁；它不执行自动回零，也不会搜索限位开关。

## 4. 白杆 5° 标定表

从软件零点开始。每到一个位置，等 OLED 显示 `STOPPED`，记录 `POS` 和同一
机械测量点的高度或实测白杆角度。右端铰链中心是转轴基准；测量点为距该中心
`L=25.8 cm` 的同一固定点。

| 顺序 | 操作 | OLED `POS` / 脉冲 | 电机轴累计理论角 | 白杆实测角度 | 高度 `h` / cm | `Δh=h-h0` / cm |
|---:|---|---:|---:|---:|---:|---:|
| 0 | 零点后不按 | 0 | 0° | 0° | `h0=` | 0 |
| 1 | `UP` 1 次 | +44 | +4.95° |  |  |  |
| 2 | `UP` 1 次 | +88 | +9.90° |  |  |  |
| 3 | `UP` 1 次 | +132 | +14.85° |  |  |  |
| 4 | 回到零点后，`DOWN` 1 次 | −44 | −4.95° |  |  |  |
| 5 | `DOWN` 1 次 | −88 | −9.90° |  |  |  |
| 6 | `DOWN` 1 次 | −132 | −14.85° |  |  |  |

正、负方向请分别从零点开始测：完成第 3 行后，连续按 `DOWN` 3 次回到 `POS 0`，
确认白杆恢复水平，再开始第 4 行。这样可分别看出正、负回程以及机械回差。

角度也可由高度计算：`θ(°) = asin(Δh / 25.8) × 180 / π`。发现机械卡住、连杆
接近极限或白杆倾斜明显时，按 `START` 锁定；不要强行完成后续测试点。
