# X42S 白杆（摆杆）首次标定结果

> 日期：2026-07-31
> 用途：后续编写步进电机控制、摆杆补偿或小球控制前，先阅读本文件。
> 结论：**不能用“3200 脉冲/圈”直接换算白杆角度。** 该数只对应电机轴；白杆经过摇臂和连杆后，必须依据本文件的实测表做插值。

## 1. 当前硬件与固件约定

| 项目 | 当前约定 |
|---|---|
| 电机/驱动 | X42S 闭环步进，`MStep=16` |
| 电机轴理论换算 | `3200` 脉冲/圈；`44` 脉冲约为电机轴 `4.95°` |
| MCU → X42S | `STP=PB13`、`DIR=PB12`、`EN=PB6`、`COM=3V3` |
| 按键 | `START=PB7`、`UP=PB15`、`DOWN=PB8`；按键另一端接 `GND` |
| 当前点动固件 | `archive/legacy_bringup/stepper_fine_jog_test.c` |
| 构建/烧录 | `make stepper-fine-jog-test`；`./flash_xds110.sh --yes --run build/stepper_fine_jog_test.out` |
| 单次点动 | `UP` 为 `+44` 脉冲；`DOWN` 为 `-44` 脉冲 |

`START` 只负责解锁/锁定，**不做自动回零**。本机构没有可用的机械限位开关。

## 2. 每次测试前的零点方法

1. 不放钢球；确认白杆运动范围内没有碰撞风险。
2. 按 `START` 解锁，用 `UP/DOWN` 单次点动，调到白杆水平。
3. 按 `START` 锁定，按开发板 `RESET`（或断电重上电）。白杆不能再被移动。
4. 重启后 OLED 显示 `POS +0`；它就是本次的软件零点。
5. 再按 `START` 解锁后才开始测试。每次按键后，必须等 OLED 显示 `STOPPED`。

## 3. 测量定义与换算

- 右端铰链中心是转轴基准。
- 高度测量点是白杆上同一固定点，距铰链中心 `L=25.8 cm`。
- 零点高度为 `h0=11.1 cm`。
- 由高度计算的白杆角度：

```text
θ_beam(°) = asin((h - h0) / 25.8) × 180 / π
```

正方向定义为该固定点高度增加；负方向定义为高度降低。

## 5. 后续控制必须使用的查表关系

以 `POS=0` 为白杆水平基准，当前只允许在已实测范围 `[-132, +132]` 内控制。
目标角度在相邻两个点之间时，按相邻点**线性插值**得到脉冲目标；不要使用一个全局“脉冲/度”常数。

### 正方向映射

| 白杆角度（°） | 0.000 | +0.444 | +1.110 | +1.777 |
|---|---:|---:|---:|---:|
| 电机目标 POS（脉冲） | 0 | +44 | +88 | +132 |

### 负方向映射

| 白杆角度（°） | 0.000 | -0.444 | -1.333 | -2.221 |
|---|---:|---:|---:|---:|
| 电机目标 POS（脉冲） | 0 | -44 | -88 | -132 |

例如，要求正向白杆 `+1.0°` 时，在 `(+0.444°, +44)` 和 `(+1.110°, +88)` 两点之间插值，初始目标约为 `+81` 脉冲。实际实现时应将结果四舍五入为整数脉冲，并限制在标定表范围内。

## 6. 已观察到的现象与限制

1. X42S 屏幕的 `±4.9° / ±9.9° / ±14.8°` 是电机轴角度，不能当作白杆角度。
2. 白杆传动比随位置和方向变化：同样 `44` 脉冲，在不同区段对应的白杆角变化不同。
3. 正、负方向的对应关系不对称；可能来自连杆几何、装配间隙或测量误差。因此未来如需高精度，还应单独补测每个方向的回程数据。
4. 本次数据只覆盖约 `+1.78°` 到 `-2.22°`，不能外推到更大角度，也不能据此设置大范围软限位。
5. 本次为开环位置标定；软件的 `POS` 是“发出的脉冲坐标”，不等于真实机械角度。若机构卡住或丢步，必须重新确认手动零点并重做测量。

## 7. 后续工作建议

1. 在相同测量点补测正回程：`+15° → +10° → +5° → 0°` 的白杆实测角度，用于量化回差。
2. 在相同测量点补测负回程：`-15° → -10° → -5° → 0°`。
3. 若将来摆杆角度目标超过本次范围，以每个 `0.5°` 或更小的白杆实测间隔扩充查表点，且始终先检查机械安全范围。
4. 小球闭环控制开始前，先把本表封装成“白杆角度目标 → 脉冲目标”的查表函数；小球位置控制输出的是白杆目标角，不应直接输出电机屏幕角度。
