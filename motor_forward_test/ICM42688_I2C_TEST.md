# ICM42688 姿态传感器首测

此测试只初始化 `I2C0` 和板载 LED；不会初始化 TB6612 的任何电机控制引脚。

## 接线

| ICM42688P 模块 | LP-MSPM0G3507 |
|---|---|
| `VCC` | `3V3` |
| `GND` | `GND` |
| `SDA/MOSI` | `PA28` |
| `SCL/SCLK` | `PA31` |
| `CS` | `3V3`，固定选择 I2C 模式 |
| `AD0/MISO` | `GND`，通常为 I2C 地址 `0x68` |
| `INT1`、`INT2` | 暂不接 |

全部是 3.3V 逻辑，禁止接到 5V。注意 I2C 两根线不能对调：`PA28` 是 SDA，`PA31` 是 SCL；这两个引脚不与当前电机、编码器、灰度传感器接线冲突。

测试固件使用 I2C repeated-start 读取寄存器，并按 MSPM0 I2C_ERR_13 要求在每次启动传输后保留时序余量。
它会自动尝试 `0x68` 和 `0x69` 两个合法 I2C 地址，并将实际成功地址保存在 `g_icm42688_i2c_address`。

## 构建与烧录

```sh
make icm42688-test
```

烧录 `build/icm42688_test.out`。

## 观察结果

- 上电时，独立红色 LED1 会短亮一次：程序已启动。
- 之后绿色 LED 周期闪烁：已读到正确身份 `WHO_AM_I = 0x47`，并持续取得六轴采样。
- 手握并快速转动传感器时，绿色脉冲之间会出现蓝色脉冲：至少一个陀螺仪原始值超过运动阈值。
- 没有绿色脉冲时，蓝色脉冲数表示故障：`1` 次为 I2C 总线超时（优先检查 SDA/SCL、模块供电及上拉），`2` 次为 NACK/总线错误，`3` 次为目标有回应但身份不是 `0x47`。

在 CCS 的 Watch 窗口还可查看：

- `g_icm42688_who_am_i`：必须为 `0x47`。
- `g_icm42688_sda_line_high`、`g_icm42688_scl_line_high`：仅为早期接线排查保留的 GPIO 快照。I2C 引脚切换为外设高阻模式后，它们可能为 `0`，不能单独据此判断总线故障；应以 `WHO_AM_I`、错误码和采样计数为准。
- `g_icm42688_read_count`：应持续增长。
- `g_icm42688_latest_sample.accelX/Y/Z`：改变模块朝向时应变化；静止平放时其中一个轴会接近重力对应的原始值。
- `g_icm42688_latest_sample.gyroX/Y/Z`：静止时接近零，转动时会明显变化。
